# Projeto-AV2-Teoria-de-Grafos
Projeto que implementa as árvore k-d, rubro negra e 2-3-4 em python.

Possui menu com as seguintes funcionalidades para usuário:

  - Inserção de nó, seguida de balancamento
  - Exclusão de nó, seguida de balanceamento
  - Busca de dados

O usuário deve fornecer os dados para que a operação seja realizada.
